# Playtest UNTITLED
The project's start scene is unchanged. To playtest:
1. In GB Studio, click an empty spot of the world map. In Settings → Starting Scene, choose **UNT_TITLE** (any X/Y works; the logo scene ignores it).
2. Run it. When you're done, set the Starting Scene back to the original one **BOOT** (id ded6baad…, start 7,14).
Shortcut: in UNT_CURB, right-click the map → "Run from here" to skip the title.
