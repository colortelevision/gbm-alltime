## Playability locks
- SCR_SplitNight is silent: no Text, Music, Show, or SFX. It only waits and sets VAR_RESCUE_LATE (it runs on thread VAR_T_SPLIT_NIGHT).
- SCR_Rite is the only cellar speaker. It sets Conner to (4,10) and Parker to (6,10) immediately before Show.
- ACT_Candle has the only On Update in the cellar. There's no GameController On Update.
- Pause Logic wraps the cutscenes and the rite. Resume happens only in SCR_EndCutscene.
- The white-out is at the end of SCR_Rite: EndCutscene → Music Stop → Fade → UNT_WHITE.
- Doors: if VAR_CUTSCENE==0 → SFX → Fade → Change Scene.
- Start calls SCR_Status via Set Input Script in every topdown On Init.

Sources: curb ← lavender, sample_town, city, Hometown, Kanto cerulean/vermillion, route 1, dj city, gbassets thomas/map/tilemap;
office/hall/house ← Kanto house1f/2f/npchouse/billshouse/dighouse/bikeshop/mart/club/silph, house, room, control room, gbassets tiles;
nave ← inannastemple(2), skytemple, TEMPLE19, INANNASTEMPLEFLAME, gbassets isis01-03, FFL2 Shrine of Isis, pyramid;
cellar/title ← basement, cave, hidden_cave, 240401 dungeons, invoke_dungeon_01, gbassets dungeon rpg/underground.
Re-running untitled_gen.py: use `SKIP_UNT_BG=1 python3 tools/untitled_gen.py` to keep art, or rerun untitled_retile.py after.

## Backgrounds (vision-composed)
All `unt_*` backgrounds are rebuilt by `tools/untitled_compose.py` from intact tile stamps cut by coordinate and checked visually:
- CURB: buildings/sidewalk/hedge from `230927-Kanto-vermillion.png`, grass/trees/sign from `sample_town.png`, asphalt road with lane dashes.
- OFFICE / HALL / HOUSE: `230927-kanto-house1f.png` kit (wall band + windows, diagonal floor, bookshelves, tables/chairs, TV, mat at door).
- NAVE / CELLAR / TITLE: `240401-dungeon2.png` kit (stone blocks, brick face, cobble floor, torches, altar dais).
Collisions in each `scn_unt_*/scene.gbsres` are regenerated to match. Re-run: `python3 tools/untitled_compose.py`.
